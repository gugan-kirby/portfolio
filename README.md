# portfolio

Personal portfolio of **Thalapathigugan K (Gugan)**, Full Stack & AI Developer. It comes in three styles, each a static site in plain HTML, CSS and JS with no build step:

| Folder | Style |
| --- | --- |
| [`clean/`](clean/) | Clean editorial layout with motion and a dark mode toggle |
| [`anime/`](anime/) | Manga style: an animated anime character, sakura petals and comic panels |
| [`shonen/`](shonen/) | Dark neon shonen style: night city, rain, lightning and an animated character |

Open any folder's `index.html` in a browser to view it.
